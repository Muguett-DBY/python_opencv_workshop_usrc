# Source and rights

This repository preserves imported teaching exercises and the original contributor history. Its current owner cannot grant a new blanket license for code or media written by other contributors. No repository-wide MIT or noncommercial grant is being invented for that material.

Keep upstream author credits, original notices, and the historical teaching reference. Obtain permission from the relevant copyright holders before redistributing material whose license is not stated. Newly added repository-maintenance tooling and original README graphics do not change the rights of the original exercises or sample media.
